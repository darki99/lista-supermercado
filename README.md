# Lista de Supermercado

## Descripción del proyecto
Este proyecto de actividad integradora 1 con titulo de App Web – Lista de Supermercado consiste en una aplicación web de lista de supermercado desarrollada
con HTML, CSS y JavaScript.

La aplicación permite al usuario agregar productos con una cantidad específica,
visualizar la lista de manera dinámica, marcar productos como comprados,
eliminarlos y ver contadores de productos totales, comprados y pendientes.

Además, la información se mantiene aunque la página se recargue mediante el uso
de localStorage, garantizando la persistencia de los datos.

## Funcionalidades
- Agregar productos
- Marcar como comprado
- Eliminar productos
- Contadores dinámicos
- Persistencia con localStorage

## Tecnologías usadas
- HTML
- CSS
- JavaScript
- GitHub

## Instrucciones de uso
1. Abrir index.html
2. Agregar productos
3. Marcar como comprado
4. Recargar y verificar persistencia
